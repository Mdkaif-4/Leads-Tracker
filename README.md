# 🔗 Lead Tracker – Chrome Extension

A lightweight Chrome Extension that helps users save and manage important URLs directly from their browser.

## 📌 About the Project

Lead Tracker is a browser extension built using HTML, CSS, and JavaScript. It allows users to save website URLs, maintain a list of useful links, and access them whenever needed.

The extension uses the browser's Local Storage API to persist saved URLs, ensuring that data remains available even after refreshing or reopening the browser.

## ✨ Features

* **Save URLs:** Add website URLs to your personal list.
* **Persistent Storage:** Saves leads using Local Storage.
* **Automatic Loading:** Previously saved URLs are restored when the extension opens.
* **Clickable Links:** Open saved URLs in a new browser tab.
* **Delete All:** Double-click the delete button to clear all saved leads.
* **Lightweight:** Simple interface with no external dependencies.

## 🛠️ Technologies Used

* HTML5 – Structure
* CSS3 – Styling
* JavaScript (ES6) – Functionality and DO
